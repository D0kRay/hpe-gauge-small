# hpe-gauge-small Wiki

This wiki site is built in CI with MkDocs and published as the `wiki-site` workflow artifact.

## Project summary

- ESP32-S3 gauge UI using LVGL on GC9A01.
- CAN/TWAI signal decoding with LittleFS-backed mapping config.
- Sensor status checks for QMI8658 IMU and PCF85063 RTC.
- WiFi AP with mobile HTTP page and live WebSocket telemetry.

## CI artifacts

- `esp-idf-build`: firmware output files (`.bin`, `.elf`, `.map`, flasher args).
- `wiki-site`: static wiki website generated by MkDocs.

Open the repository Actions workflow and download these artifacts from the latest run.
